## Completed checks

The installed toolchain remained Pebble Tool 5.0.40, SDK 4.33.1 with its bundled
ARM compiler, Python 3.13.5, Node 26.8.1, npm 11.19.0 and existing Clay dependency.
The clean build and consolidated suite passed: **175 Python tests, 43 phone
scenarios, 16 Clay checks, five real-HTTP feed scenarios and portable C suites**.
Strict compilation, address/undefined sanitizers and independent data oracles
cover merged ordering, operator calendars, date boundaries, preference migration,
journaling and storage failure cases. Phone scenarios cover manual/startup/off
location behavior, settings without incidental GPS, private home save/clear,
stale replies and retry persistence. These are automated tests, not actual
Android permission or field GPS observations.

Static budgets passed: native binary 48,784 bytes, static RAM 55,834 bytes,
resources 35,240 bytes and timetable payload 24,203 bytes. Exact-PBW launch
logged 40,004 bytes of free heap; the lowest appearance-capture sample was
40,024 bytes. These observations do not establish worst-case transfer headroom.
The standard runtime audit remains incomplete and was not relabelled passed.

All **249 native 200×228 appearance/bus-number captures** were reviewed,
covering three sizes, four themes, long English/Japanese labels, scroll endings,
preference restart/migration and all eight operator/number choices. Twelve
same-PBW probes confirmed the Scheduled/JST header survives large-row scrolling.

The final All departures run passed core manual/favourite fallback, selection
restart, all ten location statuses, invalid reply correlation, real-data
chronological/tie ordering, current-location ageing, fixed-home behaviour and
focused-trip preservation. Standard and Large passed all four themes, retaining
81 captures. Eighteen of those received the final independent visual review;
earlier full-layout reviews and the separate header probes remain distinct.

The live GitHub Pages manifest, immutable dataset-v2 payload and provenance
inventory passed read-only validation. Timetable content was not changed by
this app release. Six Hankyu poles have verified coordinates; nine Kintetsu
boarding points remain manually selectable with Distance unknown.

## Explicitly deferred checks

A repeated SDK emulator control timeout was diagnosed with GDB as a firmware
flash/logging erase stall; the debugger detached cleanly. All selected IDs and
reference were restored, and normal-relay native state verified the original
80-byte preferences with active dataset 2/pending 0. Later state/ping requests
stalled. Emulator processes were stopped with persistent flash files retained.

The owner requested wrap-up and then approved publication despite the disclosed
unfinished checks. The following were **not** marked passing:

- The remaining four final-PBW Extra Large All departures combinations and
  the unreviewed 63 captures from the interrupted final run.
- Final-PBW current/future transfer, interrupted/corrupt-update and Restore
  recovery reruns, installed-worker production HTTPS rerun and full-retention
  All departures responsiveness profiling.
- Broader physical GPS/permissions, settings persistence, connection loss and
  update recovery; outdoor readability, battery and seven days of use.

Prior builds have related emulator evidence, but that is not substituted for
an exact-final-PBW result. The unchanged strict workflow requires complete runtime evidence;
publication used a version/digest-bound one-off owner exception with the original static audit retained. Future releases
retain the normal validation and exact-candidate approval requirements.
