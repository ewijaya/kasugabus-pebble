## Checks on the exact PBW

- Consolidated automated suites and a clean Emery build passed.
- Emulator launch and navigation; native screenshots of the home screen at
  all three text sizes, Help and Settings.
- Emulator update transfer: current + future update, restart retention,
  interrupted replacement, partial-candidate restart, corrupt payload,
  incompatible manifest and interrupted HTTP all passed.
- Installed on the owner's watch through Dev Connection before approval.

## Accepted exception

After the transfer scenarios passed, the harness's final step restores the
emulator's original preferences and compares preference byte 1. It returned
0 instead of 1 on this candidate and the previous one. The failure began
after the SDK emulator was wiped (`pebble wipe`) to clear a known
flash/logging install stall, and this release does not change preference
code. The cause is not proven. The owner explicitly accepted this gap when
approving publication; it is not reported as passing.

## Not observed

Nearby with real phone location (including the new permission hint), the
Clay settings page on a phone, broader GPS/permission, connection-loss and
update-recovery behaviour, outdoor readability, battery and the seven-day
use review remain outstanding.
