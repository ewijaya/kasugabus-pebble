## What changed

The document buffer (2,200 bytes) and message queue (8 × message_t) are
allocated at startup instead of statically, with safe fallbacks on allocation
failure, and the Help text is a raw resource. The release audit now records
`image_bytes` and fails above the SDK's 65,535-byte limit or the 61,440-byte
headroom budget. Implemented by a delegated agent in an isolated worktree and
reviewed before release: the Help resource is byte-identical to the former
string, and the drawing function's stack frame (1,900 bytes) is unchanged.

## Checks on the exact PBW

- Consolidated automated suites, including the new image-budget test, and a
  clean Emery build.
- Emulator: launch, navigation, Help top to bottom, details, and all seven
  update-transfer scenarios.
- Physical: installed through Dev Connection before approval.
