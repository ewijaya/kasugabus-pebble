# KasugaBus 2.1.1 — Nearby location fix

- **Nearby works on more Android phones.** Some companion apps report the
  location's time in a different format; KasugaBus rejected those fixes and
  showed "Phone unavailable". It now accepts them. Confirmed on a Poco F4.
- **Network location fallback.** If GPS cannot give a precise fix (often
  indoors), Nearby tries a network location before giving up.
- **Clearer messages.** "No location fix - try outdoors" means the phone is
  connected but has no position; "Phone unavailable" now means the phone is
  really unavailable.
- **Automatic retry** when the phone connects after you opened Nearby.

Distances are approximate straight-line distances. Timetable content and the
timetable feed are unchanged.

Broader physical GPS/permission and connection-loss/update-recovery checks,
outdoor readability, battery observations and the seven-day use review remain
outstanding.
