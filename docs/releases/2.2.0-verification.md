## Size finding

The SDK refuses builds whose app image exceeds 65,535 bytes. 2.1.1 was 31 bytes
under; the first 2.2.0 build was over and failed. Shrinking the route-number
filter buffer from 1,024 to 32 bytes restored 631 bytes of margin.
`tests/build-budgets.json` still assumes a 104,857-byte static budget and does
not reflect this limit; correcting it and creating headroom is planned.

## Accepted exception and limits

The emulator harness's final preference-restore comparison failed after all
transfer scenarios passed, as in earlier releases; the owner accepted it.
Battery, outdoor readability and the seven-day review were not observed.
