# KasugaBus 1.0.0 — initial release

- Initial interactive app for Pebble Time 2 / Emery, with the Neon Transit
  clock-and-departure home, departure board, full trip details, favourites,
  boarding-point picker and data status.
- Offline Kintetsu and Hankyu scheduled timetables: 1,411 departures at 15
  boarding points across six stop groups, preserving operators, boarded routes,
  directions and weekday/Saturday/Sunday-public-holiday calendars.
- Japan-time bus calculations with a local-time watch clock, source-review
  notices and explicit unconfirmed coverage. Saved origin leave-by times use
  only walking allowances the user has configured.
- Phone-side Clay preferences and optional one-shot Nearby ranking for six
  verified Hankyu poles. All nine Kintetsu points remain manual choices;
  approximate straight-line distance is not a walking-time estimate.
- User-selected Neon Express launcher icon, visible in both Emery launcher
  selection states and confirmed visible and highlighted by the Time 2 owner.

The bundled service-date coverage is **1 October–27 December 2026**, with source
review due **1 November 2026**. These are scheduled departures, not live
arrivals or delay predictions. Timetable downloads use the project's reviewed
GitHub Pages feed; the app keeps current and future schedules separately and
retains usable data when a download or transfer fails.

This is an initial release with explicitly accepted validation limitations.
Automated and native Emery emulator checks cover calendars, offline lookup,
preferences, validated current/future downloads and interrupted-transfer
recovery. Physical installation, basic navigation and the launcher icon have
been observed on the owner's Time 2 with firmware **4.38.4**, a Poco F4 running
**Android 14**, and Pebble companion **1.14.0.1**. The owner also confirmed a
timetable-only update to dataset v2 and a successful feed-check timestamp.

Broader physical GPS/permission, Clay persistence, connection-loss and update
recovery checks, outdoor/glance readability, battery impact and seven days of
use remain outstanding. These results have not been inferred from emulator
success. The project verification report records evidence and the exact
approved release artifact separately.
