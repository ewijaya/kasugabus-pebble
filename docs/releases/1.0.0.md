# KasugaBus 1.0.0 — draft, not published

- Initial interactive app for Pebble Time 2 / Emery, with the Neon Transit
  clock-and-departure home, departure board, full trip details, favourites,
  boarding-point picker and data status.
- Offline Kintetsu and Hankyu scheduled timetables: 1,411 departures at 15
  boarding points across six stop groups, preserving operators, boarded routes,
  directions and weekday/Saturday/Sunday-public-holiday calendars.
- Japan-time bus calculations with a local-time watch clock, source-review
  notices and explicit unconfirmed coverage. Saved origin leave-by times use
  only walking allowances the user has configured.
- Phone-side Clay preferences and optional one-shot Nearby ranking for six
  verified Hankyu poles. All nine Kintetsu points remain manual choices;
  approximate straight-line distance is not a walking-time estimate.
- User-selected Neon Express launcher icon, visible in both Emery launcher
  selection states and confirmed visible and highlighted by the Time 2 owner.

The bundled service-date coverage is **1 October–27 December 2026**, with source
review due **1 November 2026**. These are scheduled departures, not live
arrivals or delay predictions. The validated current/future update mechanism
is implemented, but the configured GitHub Pages feed is **not deployed**;
online timetable updates are not yet available.

The final candidate is **817,565 bytes**, SHA-256
`2bddb0b092d51c7cdab6944c56a11bb377f4a97932643ee37541450bfc8bdb09`.
Its clean build, automated suites, fresh native emulator launch/navigation,

the owner's Time 2 through Dev Connection. The observed device setup is
Time 2 **v4.38.4**, Poco F4 / Android 14 and companion **1.14.0.1**.
Earlier Home → board → details navigation and later icon visibility were
