# KasugaBus 2.0.0 — larger text and more ways to browse

- Choose Standard, Large or Extra Large text on the watch or in phone settings.
  Large is the new default, including when upgrading from version 1.
- Choose Neon Dark, Neon Light, High Contrast Dark or High Contrast Light.
  Larger text wraps and scrolls, with fewer rows shown when necessary.
- Existing favourites, boarding-point choices, walking allowances and update
  history are retained when the preferences migrate to the new format.
- The store banner and description now make the coverage explicit:
  Minami-kasugaoka in Ibaraki, Osaka, Japan.
- Browse **Stops → Bus numbers**, choose an operator/number, then a boarding
  point and direction to see departures for that bus. The filter uses the
  number shown when boarding, even when a route changes number farther on.
- **Stops → All departures** merges the boarding points you select into one
  chronological board, with approximate distance breaking equal-time ties.
  Choose Current phone location, Saved home location or manual selection.
  Every entry identifies its operator, number, boarding stop and direction.
  Points without verified coordinates show **Distance unknown** and remain
  available manually or through favourites.
- Save or clear a home reference in phone settings. Home coordinates stay
  private on the phone; only distances and availability states reach the watch.
  These are straight-line distances, with no inferred walking time.
- Clearer Nearby settings separate "Use phone location for Nearby" from
  "Open Nearby on startup". Turning location off also turns startup Nearby off;
  the watch explains how to enable it. Location is requested only when needed,
  with permission, availability, timeout and accuracy states kept distinct.
- Strengthened release retry checks preserve the original listing and release
  history; authenticated PBW uploads refuse HTTP redirects.

Open KasugaBus, hold Select, choose Settings, then Text size or Colour theme.
The phone's KasugaBus settings offer the same choices.

KasugaBus covers six local stop groups; it is not an Osaka-wide journey
planner. Timetable content is unchanged by this app update. The bundled
service-date coverage remains 1 October–27 December 2026, with source review
due 1 November. The live timetable feed is dataset v2, which is separate from
app version 2.0.0. All departures are scheduled, not live arrival predictions.

Broader physical GPS/permission and connection-loss/update-recovery checks,
outdoor readability, battery observations and the seven-day use review remain
outstanding. Emulator and automated results do not establish those outcomes.
Candidate-specific installation, readability/settings checks and publication
approval are recorded separately in the verification report.

Release validation scope

The clean build and automated suites passed; 249 appearance/route captures and the core All departures cases passed. A final All departures run completed Standard/Large before an SDK emulator firmware flash/logging stall; its four Extra Large combinations were not completed. The final PBW current/future transfer, recovery and full-retention responsiveness reruns remain outstanding. These checks are deferred, not reported as passing. Broader physical GPS/settings/recovery, outdoor readability, battery and seven-day use also remain outstanding.
